# ESM 电子支援传感器模型设计文档

## 一、模型概述

**ESM**（Electronic Support Measures）是一个**被动射频信号侦收传感器模型**，自身不发射任何信号，仅通过被动接收和分析空间中的射频辐射源来完成探测任务。

**模型定位**：WSF_PASSIVE_SENSOR — 被动宽带传感。

> **实现状态标记**：✅ 已实现 | ⚠️ 接口预留，暂返回默认值 | ❌ 未实现

**核心功能：**

| 功能 | 说明 |
|------|------|
| 被动探测 | 不发射信号，仅监听空间中射频辐射源 |
| 链路预算 | 基于 Friis 自由空间传输方程的完整链路预算 |
| 方向性天线 | ISOTROPIC / GAUSSIAN / SINC2 三种方向图 + 波束指向 + FOV 约束 |
| 多波束支持 | 多波束独立天线 + 独立频段，遍历波束取最佳 SNR（对齐 AFSIM PassiveBeam） |
| 频段扫描调度 | 多频段 dwell/revisit 扫描时序模拟 |
| 双模式检测 | 直接 SNR 门限模式 + PSOS 概率扫描累积模式 |
| 发射器识别 | 基于置信度的概率引擎，支持 cTRUTH / cTABLE 规则 |
| 平台分类 | 基于检测到的发射器组合推断目标平台（cEMITTERS 模式） |
| 测量误差 | DOA/距离高斯噪声，支持固定值 + 频率相关表 + 距离百分比 |
| M/N 航迹管理 | 滑动窗口 M-of-N 建立/维持 + coast 超时删除 |
| 事件驱动调度 | DomainEvent 离散事件（Scan/Detection/Declaration/TrackInitiated/TrackDropped） |

**适用场景：** RWR（雷达告警接收机）、ELINT（电子情报）、COMINT（通信情报）等仿真建模。

## 二、模型工作流程

ESM 传感器采用**闭环被动侦收**流程，分为以下阶段：

```
┌─────────────────────────────────────────────────────────────────┐
│                        初始化阶段                                 │
│  加载基础参数 → 配置接收机（带宽/灵敏度/频段）→ 配置天线         │
│  → 添加辐射源 → 配置报告规则 → 配置 M/N 航迹参数                 │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                        信号接收阶段                               │
│  遍历辐射源列表 → 检查 active 状态 → 检查频率是否在监听频段内    │
│  → 检查 FOV 约束 → 通过则进入链路预算                            │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                        链路预算阶段                               │
│  1. 几何计算（距离、方位角、仰角）                                │
│  2. 自由空间路径损耗 FSPL = 20log₁₀(4πRf/c)                      │
│  3. 接收天线方向性增益 G_r(θ)                                    │
│  4. 极化失配损耗 + 带宽失配损耗                                   │
│  5. 接收功率 P_r = EIRP + G_r − FSPL − 损耗                      │
│  6. 噪声底（经典公式 或 系统噪声温度模型）                        │
│  7. SNR = 10log₁₀(S / (N+C+I))                                   │
│  8. 脉冲占空比惩罚：SNReff = SNR + 10log₁₀(duty_cycle)           │
│  9. 扫描调度检查：fmod(t, revisit) < dwell ?                      │
│ 10. 频率相关门限/灵敏度查询（CW/PULSED 分离路由）                 │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                      检测判决与识别阶段                            │
│                                                                   │
│  直接模式：SNReff ≥ 门限 && scan_available && P_r ≥ 灵敏度       │
│    → 立即确认探测                                                 │
│                                                                   │
│  PSOS 模式：                                                      │
│    PA = 方位重叠概率（发射天线波束指向概率）                      │
│    PF = dwell/revisit（频率重叠概率）                              │
│    PSS = PA × PF（单次扫描检测概率）                              │
│    PSS_frame = 1−(1−PSS)^dwell_count（帧级概率）                  │
│    Pd_cum = 1−(1−Pd_old)×(1−PSS_frame)（贝叶斯累积）             │
│    Pd_cum ≥ 确认阈值 → 确认探测                                   │
│                                                                   │
│  情报识别：                                                       │
│    发射器类型：time_to_declare 后按规则声明（cTRUTH/cTABLE）       │
│    平台类型：按检测到的发射器组合推断（cEMITTERS）                 │
│    M/N 航迹：滑动窗口建立/维持/coast/删除                          │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                        结果输出阶段                               │
│  航迹列表（频率/方位/仰角/距离/SNR/功率/声明类型/置信度）         │
│  DomainEvent 事件（Detection/Declaration/TrackInitiated/Dropped） │
│  航迹老化：超 coast_time 无观测 → 删除                            │
└─────────────────────────────────────────────────────────────────┘
```

**每帧调用流程：**

```
ESM_Sensor::update(sim_time, transmitters)
  for each xmtr in transmitters:
    r = attempt_detect(xmtr, sim_time)     // EM 交互
    track = get_or_create_track(id)
    if detected:
      fill_track_data()                    // 施加 DOA 误差 + 捕获信号数据
      apply_reporting()                    // 发射器识别 + 平台分类
    track_manager.OnDetectionOpportunity() // M/N 记录
  emitter_reporting.Evaluate()             // 评估发射器声明
  target_reporting.Evaluate()              // 评估平台声明
  remove_dropped_tracks()                  // M/N 删除
```

## 三、模型接口

### 3.1 基础参数（接收机配置 / ESM_Receiver）

| 参数 ID | 类型 | 范围/默认值 | 说明 |
|---------|------|-------------|------|
| position | double[3] | ENU 坐标系 (m) | 接收机在 ENU 平地坐标系中的位置 |

| bandwidth_hz | double | 默认 10 MHz | 瞬时接收带宽 |
| detection_threshold_dB | double | 默认 10.0 dB | 标量 SNR 检测门限（频率表为空时使用） |
| coast_time | double | 默认 5.0 s | 航迹最大失联时间 |
| rcvr_function | RcvrFunction | 默认 PASSIVE_SENSOR | COMM / SENSOR / PASSIVE_SENSOR / INTERFERER |
| polarization | Polarization | 默认 NONE | HORIZONTAL / VERTICAL / LHCP / RHCP / NONE |

### 3.2 天线参数（Antenna + AntennaPattern）

| 参数 ID | 类型 | 范围/默认值 | 说明 |
|---------|------|-------------|------|
| pattern.type | Type | 默认 ISOTROPIC | ISOTROPIC / GAUSSIAN / SINC2 |
| pattern.peak_gain_dBi | double | 默认 0.0 dBi | 波束轴峰值增益 |
| pattern.az_beamwidth_rad | double | 默认 π/2 (90°) | 方位 3dB 波束宽度 |
| pattern.el_beamwidth_rad | double | 默认 π/2 (90°) | 仰角 3dB 波束宽度 |
| pattern.back_lobe_floor_dB | double | 默认 -30 dB | 后瓣相对峰值增益下限 |
| pattern.minimum_gain_dBi | double | 默认 -40 dBi | 绝对增益硬下限 |
| pattern.gain_adjustment_table | FreqTable | 可空 | 频率相关增益修正 |
| boresight_az_rad | double | 默认 0 | 波束指向方位角 (rad, 北=0 顺时针+) |
| boresight_el_rad | double | 默认 0 | 波束指向仰角 (rad) |
| scan_mode | ScanMode | 默认 FIXED | FIXED / AZ_SCAN / EL_SCAN / AZ_EL_SCAN |
| fov_min_az_rad | double | 默认 -π | FOV 方位下界 |
| fov_max_az_rad | double | 默认 π | FOV 方位上界 |
| fov_min_el_rad | double | 默认 -π/2 | FOV 仰角下界 |
| fov_max_el_rad | double | 默认 π/2 | FOV 仰角上界 |
| min_range_m | double | 默认 0 | FOV 最小距离 |
| max_range_m | double | 默认 1e9 | FOV 最大距离 |

### 3.3 波束参数（ESM_Beam） ✅ 多波束支持

对应 AFSIM `PassiveBeam`。每个波束独立配置天线和监听频段，对同一目标所有波束各自检测后取 SNR 最优。

| 参数 ID | 类型 | 范围/默认值 | 说明 |
|---------|------|-------------|------|
| beam_index | int | 1-based | 波束编号 |
| antenna | Antenna | 独立配置 | 该波束的独立天线（方向图 + 指向 + FOV） |
| frequency_bands | vector\<FrequencyBand\> | 独立配置 | 该波束独立监听的频段列表 |

**C-API：**
| 函数 | 说明 |
|------|------|
| `ESM_AddBeam()` | 添加新波束，返回波束编号 |
| `ESM_RemoveBeam(index)` | 删除指定波束 |
| `ESM_GetBeamCount()` | 获取波束总数 |
| `ESM_SetBeamAntennaPattern(index, ...)` | 配置指定波束的天线方向图 |
| `ESM_SetBeamAntennaBoresight(index, az, el)` | 配置指定波束的天线指向 |
| `ESM_SetBeamAntennaFov(index, ...)` | 配置指定波束的天线 FOV |
| `ESM_AddBeamFrequencyBand(index, ...)` | 为指定波束添加监听频段 |

**向后兼容：** 默认一个 Beam 1，旧的 `ESM_SetAntennaPattern()` 等函数操作 Beam 1，无需修改现有代码。

### 3.4 频段参数（FrequencyBand）

| 参数 ID | 类型 | 范围/默认值 | 说明 |
|---------|------|-------------|------|
| lower_hz | double | - | 监听频段下边界 (Hz) |
| upper_hz | double | - | 监听频段上边界 (Hz) |
| dwell_time_s | double | 默认 1.0 s | 每次扫描周期内的驻留时长 |
| revisit_time_s | double | 默认 1.0 s | 完整扫描周期，须 ≥ dwell_time_s |

**扫描调度规则：** 在时刻 t，当 `fmod(t, revisit_time_s) < dwell_time_s` 时，该频段处于激活状态。`dwell == revisit` 表示固定（始终监听）。

### 3.4 频率相关门限表（FreqTable）

| 参数 ID | 类型 | 说明 |
|---------|------|------|
| detection_threshold_table | FreqTable | 频率 → SNR 门限 (dB)，非空时覆盖标量值 |
| sensitivity_table | FreqTable | 频率 → 最小可检测功率 (dBm) |
| cw_detection_threshold_table | FreqTable | CW 信号 SNR 门限表，优先级高于通用表 |
| pulsed_detection_threshold_table | FreqTable | PULSED 信号 SNR 门限表，优先级高于通用表 |
| cw_sensitivity_table | FreqTable | CW 信号灵敏度表 |
| pulsed_sensitivity_table | FreqTable | PULSED 信号灵敏度表 |

**门限路由逻辑：** 信号类型对应新表非空 → 查新表 → 通用表非空 → 查通用表 → 标量值。

### 3.5 噪声模型参数

| 参数 ID | 类型 | 默认值 | 说明 |

### 5.2 单次交互结果（ESM_Interaction）

## 六、关键算法

### 6.1 自由空间路径损耗（FSPL）

$$
\text{FSPL} = 20\log_{10}\left(\frac{4\pi R f}{c}\right) \quad (\text{dB})
$$

其中 $c = 3.0 \times 10^8$ m/s，$R < 1.0$ m 时取 0 dB（近场保护）。

速查表：

| 距离 | 1 GHz | 3 GHz | 10 GHz |
|------|-------|-------|--------|
| 1 km | 92.4 dB | 102.0 dB | 112.4 dB |
| 10 km | 112.4 dB | 122.0 dB | 132.4 dB |
| 50 km | 126.4 dB | 136.0 dB | 146.4 dB |
| 100 km | 132.4 dB | 142.0 dB | 152.4 dB |

### 6.2 接收功率（Friis 传输方程）

$$
P_r (\text{dBm}) = P_t + G_t + G_r(\theta) - \text{FSPL} + \text{PolLoss} + \text{BwLoss} - L_{ohmic} - L_{line}
$$

### 6.3 天线方向图增益

**ISOTROPIC：** $G(\theta) = G_{peak}$

**GAUSSIAN：**
$$
G(\theta_{az},\theta_{el}) = G_{peak} - 12\left[\left(\frac{\theta_{az}}{BW_{az}}\right)^2 + \left(\frac{\theta_{el}}{BW_{el}}\right)^2\right] \quad (\text{dBi})
$$

**SINC2：**
$$
G(\theta) = G_{peak} + 20\log_{10}\left|\text{sinc}\left(\frac{\pi\theta}{BW_{avg}}\right)\right|^2 \quad (\text{dBi})
$$
其中 $\theta = \sqrt{\theta_{az}^2 + \theta_{el}^2}$，$BW_{avg} = (BW_{az} + BW_{el})/2$。

后瓣钳位：$G_{rel} = \max(G_{rel}, back\_lobe\_floor\_dB)$

### 6.4 极化失配损耗

| 极化组合 | 损耗 |
|---------|------|
| 同向极化 / 一方为 NONE | 0 dB |
| 正交线极化 (H↔V) | -30 dB |
| 反向圆极化 (LHCP↔RHCP) | -30 dB |
| 圆↔线 | -3 dB |

### 6.5 带宽失配损耗

$$
\Delta P_{BW} = \begin{cases}
0, & B_{sig} \le B_{rcv} \\
10\log_{10}(B_{rcv} / B_{sig}), & B_{sig} > B_{rcv}
\end{cases}
$$

### 6.6 噪声底计算

**无损耗经典公式：**
$$
P_{noise} = -174 + 10\log_{10}(B) + NF \quad (\text{dBm})
$$

**有损耗系统噪声温度模型：**
$$
T_{ant}(el) = \begin{cases} 50 + 20\cos(el), & el > 0 \\ 290\text{ K}, & el \le 0 \end{cases}
$$

$$
T_{sys} = T_{ant} \cdot L_{line} + T_0(L_{line} - 1) + T_0(NF_{lin} - 1)
$$

$$
P_{noise} = 10\log_{10}(k_B \cdot T_{sys} \cdot B) + 30 \quad (\text{dBm})
$$

其中 $T_0 = 290$ K，$k_B = 1.380649 \times 10^{-23}$ J/K。

**显式噪声功率覆盖：** $explicit\_noise\_power\_dBm > -1e20$ 时直接返回该值。

**噪声乘数效应：** $P_{noise\_eff} = P_{noise} + 10\log_{10}(M)$

### 6.7 SNR 计算

$$
\text{SNR} = 10\log_{10}\left(\frac{S_{lin}}{N_{lin} + C_{lin} + I_{lin}}\right) \quad (\text{dB})
$$

**脉冲占空比惩罚：** $\text{SNR}_{eff} = \text{SNR} + 10\log_{10}(d)$，$d \in (0, 1]$。

### 6.8 检测判决（直接模式）

同时满足以下条件判为探测成功：

1. `transmitter.active == true`
2. 载波频率在监听频段内
3. 信号在接收天线 FOV 内
4. `scan_available == true`（接收机当前在驻留窗口）
5. $\text{SNR}_{eff} \ge threshold$
6. $P_r \ge sensitivity$

### 6.9 PSOS 概率扫描累积模型

与 AFSIM WSFESM_SENSOR 的 `ComputePSOS_Effects` 算法对齐。

**方位重叠概率 PA：**

$$
G_{req\_norm} = \frac{S_{req}}{S_{iso} \cdot G_{t\_max}}
$$

| 方向图类型 | PA 计算方式 |
|-----------|-----------|
| ISOTROPIC | PA = 1.0 |
| GAUSSIAN | 解析解：$az_{half} = BW \cdot \sqrt{-\ln(G_{req\_norm})/a}$，$a = 4\ln 2$ |
| SINC2 | 1000 点数值采样 |

**频率重叠概率 PF：** $\text{PF} = \min(dwell\_time / revisit\_time, 1.0)$

**单次扫描概率 PSS：** $\text{PSS} = \text{PA} \times \text{PF}$

**帧级概率：** $\text{PSS}_{frame} = 1 - (1 - \text{PSS})^{N_{dwell}}$，$N_{dwell} = \max(1, frame\_time / revisit\_time)$

**贝叶斯累积：** $P_{cum}^{(n)} = 1 - (1 - P_{cum}^{(n-1)}) \cdot (1 - \text{PSS}_{frame})$

**确认判决：** $\text{PSS} > 0$ 且 $P_{cum} \ge required\_pd$ → 确认探测。

**衰减：** $\text{PSS} = 0$ 时 $P_{cum} \gets P_{cum} \times 0.8$；$P_{cum} < 0.5$ 则置零。

### 6.10 DOA 测量误差模型

对应 AFSIM `WsfStandardSensorErrorModel`。

**有效 sigma 计算：**
$$
\sigma_{az} = \max(azimuth\_error\_sigma\_rad,\;azimuth\_error\_table.lookup(f))
$$

负的固定 sigma 值表示距离百分比模式：$\sigma_{az} = |sigma| \times 0.01 \times true\_range$

**误差施加：** $\hat{az} = az + \mathcal{N}(0, \sigma_{az})$，$\hat{el} = el + \mathcal{N}(0, \sigma_{el})$

**测距时间模型：** $track\_age \ge ranging\_time\_s$ 时 $range\_valid = true$。

### 6.11 发射器类型识别

对应 AFSIM `WsfEmitterTypeReporting`。

**cTRUTH 规则：** 始终以 100% 置信度报告真实类型。

**cTABLE 规则：** 从 `[0, 1]` 抽取均匀随机数，按累积置信度边界匹配声明类型。

**时间调度：**
1. 首次探测后等待 `time_to_declare` 秒 → 首次声明
2. 之后每 `time_to_reevaluate` 秒 → 重新评估（可改变声明类型）

### 6.12 目标平台分类

对应 AFSIM `WsfTargetTypeReporting`。

**cEMITTERS 模式：** 根据已探测到的发射器 ID 组合匹配目标平台类型。

例如：
```
检测到 {"Radar_TypeA", "IFF_Mode3"} → 声明 "Fighter_J11"
检测到 {"Radar_TypeB", "Jammer_X"}  → 声明 "Bomber_H6"
```

### 6.13 M/N 航迹管理

对应 AFSIM `WsfSensorTracker`。

**状态机：**
```
NONE ──(首次检测)──→ INITIATING ──(M/N 满足)──→ MAINTENANCE
                                                   │
                                             (M/N 不满足)
                                                   ↓
                                                 COAST
                                              │        │
                                    (M/N 重新满足)   (超 coast_time)
                                              ↓        ↓
                                        MAINTENANCE  DROPPED
```

**滑动窗口**：每帧将本次检测结果推入窗口，超出 N 的旧记录弹出，统计窗口内检测次数与 M 比较。
