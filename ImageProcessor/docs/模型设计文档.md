# ImageProcessor 图像目标探测跟踪与识别模型设计文档

## 一、模型概述

**ImageProcessor** 是一个**光电/红外/SAR 图像目标探测、跟踪与识别处理模型**，接收图像/视频帧输入，提取检测目标，为每个目标维护航迹，基于 Johnson 准则执行目标识别状态机。

**模型定位**：图像/视频传感器处理器。

> **实现状态标记**：✅ 已实现 | ⚠️ 接口预留，暂返回默认值 | ❌ 未实现

**核心功能：**

| 功能 | 说明 |
|------|------|
| 图像/视频处理 | 接收静态图像和视频流帧输入，提取检测目标 |
| 6D Kalman 滤波 | 复用 TargetMeasurementDataProcessor 的 KalmanFilterND（匀速模型），预测+更新平滑位置、估计速度 |
| Johnson 准则识别 | 基于像素数和场景分析因子(SAF)计算检测/分类/识别概率 |
| 目标识别状态机 | 7 级递进状态机（UNDETECTED → IDENTIFIED），带延迟确认和 coast 降级 |
| 视频流持续跟踪 | 跨帧航迹保持、流编号变化重置、KF/CV 滤波器平滑 |
| 静态图像一次性报告 | 单帧图像目标的一键式航迹输出 |
| 航迹生命周期 | 创建/更新/coast/回收全生命周期管理 |
| 分类/识别持久化 | 状态不后退：一旦目标达到更高状态，始终维持最佳识别结果 |
| 方位/俯仰角报告 | 基于传感器位置和目标位置的几何计算 |
| 信噪比、像素数报告 | 信号强度和目标尺寸输出 |
| 传感器误差传播 | 距离/方位/俯仰/径向速率误差传播至航迹 |

**适用场景：** EO/IR 光电传感器、SAR 成像雷达、视频监控、目标侦察等图像情报仿真建模。

## 二、模型工作流程

ImageProcessor 采用**图像帧驱动**处理流程，分为以下阶段：

```
┌─────────────────────────────────────────────────────────────────┐
│                        初始化阶段                                │
│  加载基础参数 → 配置像素阈值/SAF因子/延迟时间 → 配置coast时间       │
│  → 配置报告选项 → 配置随机种子                                    │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                        图像帧处理阶段                             │
│  接收图像帧(IP_ImageInput)                                      │
│  → 标记所有 Status 为 stale（准备 coast 检测）                   │
│  → 遍历每个检测目标:                                             │
│     1. 目标识别状态评估（Johnson 准则 + FSM）                    │
│     2. 如未检测到(UNDETECTED)，跳过                               │
│     3. 创建/查找航迹（视频流持久/静态一次性）                    │
│     4. Kalman/CV 滤波器平滑测量                                  │
│     5. 填充航迹属性（位置/SNR/像素/方位俯仰）                    │
│     6. UpdateTrack aux data（分类/识别持久化）                    │
│  → PurgeOldTracks：清理超时视频航迹                               │
│  → 处理 stale Status 的 coast 降级                               │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                        结果输出阶段                               │
│  航迹列表（位置/识别状态/分类时间戳/识别时间戳/SNR/像素数）      │
│  航迹老化：超 coast_time 无更新 → 删除                           │
└─────────────────────────────────────────────────────────────────┘
```

**每帧调用流程：**

```
ImageProcessor::ProcessImage(input, output)
  ImageProcessingInitiated()           // 标记所有 status 为 stale
  for each object in input.objects:
    evaluateObjectState(simTime, object)  // Johnson + FSM
    if UNDETECTED: continue
    get_or_create_track()              // 视频流/静态分支
    fill_track_properties()            // 位置/SNR/像素/误差
    updateTrackAuxData()               // CLASSIFIED/IDENTIFIED 时间戳
  purgeOldTracks()                     // 清理超时航迹
  processCoastDowngrade()              // stale 状态 coast 降级
```

## 六、关键算法

### 6.1 Johnson 准则目标识别

Johnson 准则将目标探测能力分为三个等级，每个等级有对应的场景分析因子(SAF, N50)：

| 等级 | N50 (SAF) | 说明 |
|------|-----------|------|
| 检测 (Detection) | `detectionSAF` | 分辨目标存在 |
| 分类 (Classification) | `classificationSAF` | 分辨目标类别（如坦克/卡车） |
| 识别 (Identification) | `identificationSAF` | 分辨目标具体型号（如 T72/M1） |

#### 概率公式

所有三个等级使用统一的 Johnson 概率函数：

$$P(N) = \frac{N^{2.7 + 0.7N}}{1 + N^{2.7 + 0.7N}}$$

其中 $N = \frac{\text{objectSize}}{\text{SAF}}$ 为目标尺寸与 SAF 之比。

#### 目标尺寸计算

**直接像素数模式**（`averageAspectRatio = 0`）：

$$\text{objectSize} = \text{pixelCount}$$

**线对模式**（`averageAspectRatio > 0`，推荐）：

$$\text{SD} = \sqrt{\frac{\text{pixelCount}}{\text{AR}}} \quad (\text{最短边像素数})$$

$$\text{objectSize} = \frac{\text{SD}}{2} \quad (\text{线对数})$$

其中 AR 为 `averageAspectRatio`。

#### 速查表（AR=4.0，像素→各等级概率）

| 像素数 | objectSize | P(检测) | P(分类) | P(识别) |
|-------|-----------|---------|---------|---------|
| 10 | 0.79 | 0.42 | 0.03 | 0.01 |
| 50 | 1.77 | 0.80 | 0.11 | 0.03 |
| 100 | 2.50 | 0.90 | 0.20 | 0.06 |
| 200 | 3.54 | 0.97 | 0.38 | 0.14 |
| 500 | 5.59 | 0.997 | 0.66 | 0.34 |
| 1000 | 7.91 | 1.0 | 0.84 | 0.56 |

### 6.2 目标识别状态机

状态机包含 7 个状态，采用**两段式递进**结构：

```
帧状态判定（Johnson 概率）
         │
         ▼
┌──────────────┐    帧状态 ≥ DETECTED     ┌──────────────────┐
│  UNDETECTED  │ ───────────────────────→ │ WAITING_DETECTION │
│              │ ←── coast 超时降级 ──── │                  │
└──────────────┘                          └────────┬─────────┘
                                                   │ 延迟期满
                                                   ▼
┌──────────────┐    帧状态 ≥ CLASSIFIED    ┌──────────────────┐
│  DETECTED    │ ───────────────────────→  │WAITING_CLASSIFIC.│
│              │ ←── coast 超时降级 ────  │                  │
└──────────────┘                           └────────┬─────────┘
                                                    │ 延迟期满
                                                    ▼
┌──────────────┐    帧状态 ≥ IDENTIFIED    ┌──────────────────┐
│  CLASSIFIED  │ ───────────────────────→  │WAITING_IDENTIFIC.│
│              │ ←── coast 超时降级 ────  │                  │
└──────────────┘                           └────────┬─────────┘
                                                    │ 延迟期满
                                                    ▼
┌──────────────┐
│  IDENTIFIED  │
│              │ ←── coast 超时降级
└──────────────┘
```

#### 状态过渡规则

| 当前状态 | 进入条件 | 退出条件 | Coast 超时 |
|---------|---------|---------|-----------|
| UNDETECTED | 初始 | frameState ≥ DETECTED → WAITING_DETECTION | — |
| WAITING_DETECTION | UNDETECTED 帧达标 | 延迟期满 → DETECTED | `transitionCoastTime` → coast 帧状态 |
| DETECTED | 延迟期满 | frameState ≥ CLASSIFIED → WAITING_CLASSIFICATION | `detectionCoastTime` → coast 帧状态 |
| WAITING_CLASSIFICATION | DETECTED 帧超CLASSIFIED | 延迟期满 → CLASSIFIED | `transitionCoastTime` → coast 帧状态 |
| CLASSIFIED | 延迟期满 | frameState ≥ IDENTIFIED → WAITING_IDENTIFICATION | `classificationCoastTime` → coast 帧状态 |
| WAITING_IDENTIFICATION | CLASSIFIED 帧超IDENTIFIED | 延迟期满 → IDENTIFIED | `transitionCoastTime` → coast 帧状态 |
| IDENTIFIED | 延迟期满 | 永不主动退出 | `identificationCoastTime` → coast 帧状态 |

**Coast 机制**：进入 coast 时记录最佳帧状态，超时后切换到该帧状态（而非直接 UNDETECTED）。

#### 结果字符串映射

| 当前 FSM 状态 | 帧结果 | 含义 |
|--------------|--------|------|
| IDENTIFIED | "IDENTIFIED" | 已识别 |
| WAITING_IDENTIFICATION / CLASSIFIED | "CLASSIFIED" | 已分类 |
| WAITING_CLASSIFICATION / DETECTED | "DETECTED" | 已检测 |
| 其他 | "UNDETECTED" | 未检测到 |

### 6.3 航迹 Aux Data（分类/识别时间戳持久化）

对应 AFSIM `WsfImageProcessor::UpdateTrack` 逻辑：

```
1. 检查航迹已有 classifiedTime / identifiedTime（来自 TrackState 持久化）
2. 若已识别(identifiedTime ≥ 0) 或 帧结果 == "IDENTIFIED":
     → 设置 identifiedTime = simTime, classifiedTime = simTime
3. 否则若已分类(classifiedTime ≥ 0) 或 帧结果 == "CLASSIFIED":
     → 设置 classifiedTime = simTime, identifiedTime = -1
4. 否则（仅检测到）:
     → 设置 classifiedTime = -1, identifiedTime = -1
```

**状态不后退**：一旦目标达到 IDENTIFIED，即使后续帧概率下降（coast），输出始终报告 IDENTIFIED。这一行为通过 TrackState 的持久化 `identifiedTime`/`classifiedTime` 实现。

### 6.4 方位角/俯仰角计算

当 `reportsBearingElevation = true` 时，基于传感器和目标位置计算：

```
dx = targetX - sensorX
dy = targetY - sensorY
dz = targetZ - sensorZ
range = sqrt(dx² + dy² + dz²)
bearing = atan2(dy, dx)
elevation = asin(-dz / range)
```

### 6.5 航迹生命周期管理

#### 视频流航迹

| 阶段 | 行为 |
|------|------|
| 创建 | 首帧遇到新 targetIndex → 创建 TrackState（trackId/streamNumber/truthName） |
| 更新 | 后续帧同 targetIndex → 复用 TrackState，检查 streamNumber 变化 |
| Coast | 目标未出现 → status 标记 stale，无有效 track 输出 |
| Coast 超时 | 超过 `coastTime` → 删除 TrackState 和对应 Status |
| 流切换 | streamNumber 变化 → 若存在滤波器则重置 |

#### 静态图像航迹

- 每帧对每个目标创建新 `trackId`（`m_nextTrackId++`）
- 不持久化 TrackState
- 一次性输出后不保留

### 6.6 航迹回收（PurgeOldTracks）

```
for each TrackState:
    timeSinceLastUpdate = imageTime - track.updateTime
    if timeSinceLastUpdate > coastTime:
        m_statusList.erase(targetIndex)
        m_trackList.erase(it)
```

### 6.7 Coast 降级（ImageProcessingCompleted）

帧处理完毕后，未被本帧更新的 Status（stale）执行 coast 检查：

```
for each Status:
    if status.IsStale():
        根据当前状态选择 coast 时间
        if CoastTimeExceeded(simTime, UNDETECTED, coastTime):
            status.EnterState(UNDETECTED, simTime, 0.0)
```

## 九、构建方法

**依赖：** CMake ≥ 3.14，C++11 编译器，Eigen 3.4.0，TargetMeasurementDataProcessor（滤波器）

```bash
# 配置并构建
cmake -B build -S .
cmake --build build

# 构建产物
#   build/libip_core.a         — 静态库
#   build/libip_dll.dll        — 动态链接库
#   build/ip_demo.exe          — 演示程序

# 运行测试
./build/ip_demo.exe

# Eigen 路径覆盖
cmake -B build -DEIGEN3_INCLUDE_DIR=<your_eigen_path>
```

## 十、❌ 未实现功能

| 功能 | 说明 |
