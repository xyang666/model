# TMD 目标测量数据处理模型设计文档

## 一、模型概述

**TMD**（Target Measurement Data Processor）是一个目标测量数据处理模型，接收雷达/光电/红外传感器的原始测量值，通过坐标变换和 Kalman 滤波输出目标在世界系下的位置、速度及质量指标。

**模型定位**：数据处理与融合模型。

> **实现状态标记**：✅ 已实现 | ⚠️ 预留/占位 | ❌ 未实现

**核心功能：**

| 功能 | 说明 |
|------|------|
| 多传感器融合 | 雷达/光电/红外可同时处理，按 sensorType 分发至对应的观测函数 |
| CMKF 架构 | 坐标转换 + 线性 Kalman 滤波，非线性部分局限在观测模型中 |
| 多目标跟踪 | 按 targetId 分发到独立航迹，每目标独立滤波器 |
| M/N 航迹管理 | 滑动窗口 M-of-N 建立/维持/coast/超时删除 |
| KF/EKF/UKF 切换 | 统一回调接口，通过 filterType 选择滤波器 |
| 坐标变换 | ECEF ↔ NED ↔ ENU ↔ LLA 完整变换链 |
| 质量评估 | NIS 卡方检验、DRMS 误差、跟踪质量、误差椭球 |
| 参考系变换 | `CoordTransform` 任意两笛卡尔参考系间 SE3 变换 |

## 二、模型工作流程

### 2.1 整体流程

```
测量输入（雷达 RBE / 光电像素 / 红外像素）
       │
       ▼
computeObservation()      ← 子类实现：z、H、R
  │
  ├─ 雷达：RBE → Body → NED → 世界系（三步协方差传播）
  ├─ 光电：像素 → 方位角 → 世界系（二步协方差传播）
  └─ 红外：像素 → 方位角 → 世界系（二步协方差传播）
       │
       ▼
filter->predict(dt)       ← 状态外推（匀速模型——当前默认、支持线性非线性运动学模型）
       │
       ▼
filter->setR(R)
filter->update(z)         ← 测量更新
       │
       ▼
quality.recordUpdate()    ← NIS 统计
       │
       ▼
fill_output()             ← 输出位置/速度/协方差/质量指标
```

### 2.2 每帧调用流程

```
Tracker::ProcessMeasurement(measurement, output)
  getTrack(input.targetId)           // 按 targetId 查找/创建航迹
  llaToEcef()                        // 传感器位置转换

  // 按传感器类型分发观测函数
  switch input->sensorType:
    RADAR → RadarTracker::computeObservation (RBE→Body→NED→ECEF)
    EO    → EOTracker::computeObservation    (像素→角度→ECEF)
    IR    → IRTracker::computeObservation    (像素→角度→ECEF)

  filter->predict(dt)                // 时间外推
  filter->setR(R)
  filter->update(z)                  // 测量更新
  quality.recordUpdate()             // NIS
  fill_output()                      // 输出填充
  M/N 窗口更新                        // 检测计数/总量维护
```

### 2.3 多传感器融合

```
                                ┌─────────────────┐
  TM_RadarMeasurement ─────────→│ RadarTracker    │
  (range, az, el)               │ setSensorFunc(0)│
                                └────────┬────────┘
                                         │
  TM_EOMeasurement ────────────→┌────────┴────────┐
  (pixelU, pixelV)              │ EOTracker       │
                                │ setSensorFunc(1)│
                                └────────┬────────┘
                                         │
  TM_IRMeasurement ────────────→┌────────┴────────┐   obsFuncs_[3]
  (pixelU, pixelV)              │ IRTracker       │ ───→ dispatch by
                                │ setSensorFunc(2)│     sensorType
                                └────────┬────────┘
                                         │
                                         ▼
                                  同一个 TrackData
                                   同一个滤波器
```

每个传感器子类在构造时通过 `setSensorFunc(sensorType, lambda)` 注册自己的观测函数。
`ProcessMeasurement` 从 `input->sensorType` 查表分发，同 track 的不同传感器观测共同更新一个滤波器。

### 2.4 雷达测量处理链路（三步协方差传播）

```
第一步：RBE → Body（Jacobian 传播）
  cov_body = J * diag(σ²) * Jᵀ           J 为 RBE→Body 的 3×3 Jacobian

第二步：Body → NED（姿态矩阵旋转）
  cov_ned  = R_bn * cov_body * R_bnᵀ     R_bn 为输入 attitude 矩阵

第三步：NED → 世界系（CoordTransform）
  cov_world = R_ne * cov_ned * R_neᵀ     R_ne 为 NED→ECEF 旋转

位置：p_world = CoordTransform.applyPos(p_ned)
```

## 六、关键算法

### 6.1 滤波器统一回调接口

所有滤波器通过 `FilterBase` 的四个回调配置系统模型，接口统一：

| 方法 | 签名 | 用途 |
|------|------|------|
| `setStateFunc` | `(x, dt) → x'` | 状态转移预测 |
| `setStateJacobian` | `(x, dt) → F` | 协方差传播 Jacobian |
| `setMeasureFunc` | `(x) → z_pred` | 预测测量值 |
| `setMeasureJacobian` | `(x) → H` | 观测 Jacobian |
| `setQ` | `Q` | 过程噪声协方差 |
| `setR` | `R` | 测量噪声协方差 |

`predict(dt)` 内部调用 `f(x, dt)` 和 `F(x, dt)` 进行状态/协方差外推。
`update(z)` 内部调用 `h(x)` 和 `H(x)` 进行测量更新。

### 6.2 三种滤波器对比

| 特性 | KF（KalmanFilterND） | EKF（ExtendedKF） | UKF（UnscentedKF） |
|------|---------------------|-------------------|-------------------|
| 状态转移 | 回调函数 | 回调函数 | 回调函数 |
| 协方差传播 | 需 F = ∂f/∂x | 需 F = ∂f/∂x | **不需要**，Sigma 点自动传播 |
| 观测模型 | 回调函数 | 回调函数 | 回调函数 |
| 观测更新 | 需 H = ∂h/∂x | 需 H = ∂h/∂x | **不需要**，Sigma 点自动传播 |
| Jacobian 推导 | 需提供 | 需提供 | **不需要** |
| 精度 | 线性（一阶） | 一阶泰勒展开 | 二阶（无偏） |
| 适用场景 | 线性系统 | 弱非线性 | 强非线性 |

**KF（KalmanFilterND）：**
```
predict: x' = f(x, dt)
         P' = F · P · Fᵀ + Q          F = F(x, dt)

update:  z_pred = h(x)
         y = z - z_pred
         S = H · P · Hᵀ + R           H = H(x)
         K = P · Hᵀ · S⁻¹
         x += K · y
         P = (I - K · H) · P
```

**EKF（ExtendedKalmanFilter）：**
与 KF 公式相同，但 f/F/h/H 均为**非线性函数**，每次在**当前状态处**计算 Jacobian：
```
F = F_(x, dt)    当前状态处的线性化
H = H_(x)        当前状态处的线性化
```

**UKF（UnscentedKalmanFilter）：**
```
predict: 生成 Sigma 点 → 通过 f 传播 → 加权恢复 x', P'
update:  生成 Sigma 点 → 通过 h 传播 → 加权恢复 z_pred, S
         K = P_xz · S⁻¹
         x += K · (z - z_pred)
         P -= K · S · Kᵀ
```
优点：**不需要计算 Jacobian**，Sigma 点自动传播非线性，精度可达二阶。

### 6.3 当前实现：CMKF

**原理：** 在 `computeObservation` 中将雷达 RBE 转换到世界系直角坐标，滤波器内部使用线性 KF。

**RBE → 世界系链路：**
```
RBE → Body      cov_body  = J · diag(σ²) · Jᵀ        （Jacobian 传播）
Body → NED      cov_ned   = R_bn · cov_body · R_bnᵀ  （姿态矩阵旋转）
NED → 世界系    cov_world = R_ne · cov_ned · R_neᵀ   （CoordTransform）
```

**优缺点：**
- 优势：滤波器保持纯线性，计算量小
- 劣势：Jacobian 在测量点计算而非预测点，存在有偏估计问题
- 替代：直接使用 UKF 可跳过 Jacobian 推导，Sigma 点自动处理非线性转换

### 6.5 NIS 质量评估

```
NIS = yᵀ · S⁻¹ · y

y = z - H · x_pred    新息
S = H · P · Hᵀ + R    新息协方差

理想 NIS ~ χ²(dim)，dim = 3（位置观测）
```

## 九、坐标参考系

| 宏 | 值 | 说明 |
|----|----|------|
| `TM_FRAME_ECEF` | 0 | 地心地固直角坐标系（当前世界系） |
| `TM_FRAME_NED` | 1 | 北-东-地 局部坐标系 |
| `TM_FRAME_ENU` | 2 | 东-北-天 局部坐标系 |
| `TM_FRAME_BODY` | 3 | 传感器本体坐标系 |
| `TM_FRAME_LLA` | 4 | WGS84 大地坐标 |
| `TM_FRAME_ECI` | 5 | 地心惯性系（J2000） |
| `TM_FRAME_ORBITAL` | 6 | 轨道系：x-矢径方向(+R), z-轨道正法向 |

### 传感器本体系定义

```
x — 前向（瞄准线 boresight）
y — 右向
z — 下向（右手系）

球坐标 RBE（在本体系中）：
  range     — 斜距
  azimuth   — 方位角，x-y 平面内从 x 轴逆时针为正
  elevation — 俯仰角，从 x-y 平面向上为正
```
